# Google Play Store Publish Directory

This directory is created to organize and store all the files required for building and publishing your Android app.

## Folder Structure

- `aab/` — Put your production Android App Bundle (.aab) files here.
- `apk/` — Put your testing/sideloadable Android Package (.apk) files here.
- `graphics/` — Put store listing graphics here:
  - App Icon (512x512 PNG)
  - Feature Graphic (1024x500 PNG)
  - Screenshots (phone and tablet screenshots)
- `metadata/` — Put text descriptions, privacy policy drafts, and credentials.
